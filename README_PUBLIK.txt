SDN 305 Maluku Tengah — paket siap publik

CARA CEPAT PUBLIKASI (TANPA CODING)
1. Ekstrak ZIP ini.
2. Buka layanan hosting statis seperti Netlify Drop atau GitHub Pages.
3. Upload folder yang berisi index.html dan folder assets.
4. Setelah selesai, hosting akan memberi alamat publik yang bisa dibagikan.

CATATAN ADMIN
- Dashboard Admin tetap bekerja untuk edit lokal di browser.
- Data localStorage TIDAK tersinkron ke perangkat lain.
- Jangan menganggap login Admin sebagai keamanan server.
- Untuk CMS online yang bisa dipakai kepala sekolah/operator dari HP atau komputer mana pun, diperlukan backend/database dan autentikasi server.

Sebelum publikasi:
- Ganti foto placeholder dengan foto sekolah asli melalui Dashboard Admin.
- Isi nomor WhatsApp/telepon, email, media sosial, data guru, siswa, berita, agenda, galeri, prestasi, dan kegiatan.
