SDN 305 Maluku Tengah — Website Resmi (versi final)

CARA MENJALANKAN:
1. Ekstrak ZIP.
2. Buka folder SDN305_Maluku_Tengah_V2.
3. Klik dua kali index.html.
4. Tombol Admin menggunakan akun awal:
   Username: admin
   Password: admin305

FITUR:
- Tampilan responsif HP/laptop
- Profil sekolah
- Guru/Tendik
- Data siswa kelas I-VI
- Berita + pencarian
- Agenda dan pengumuman
- Galeri foto
- Prestasi
- Kegiatan/ekstrakurikuler
- Kontak
- Dashboard admin
- Upload logo/foto (disimpan di browser)
- Edit/hapus/tambah data
- Backup data JSON
- Pengaturan username/password lokal

CATATAN PENTING:
Versi ini adalah website statis/offline. Data admin disimpan di localStorage browser. Jika website akan dipasang online dan dikelola oleh kepala sekolah/operator dari beberapa perangkat, sebaiknya dibuat versi produksi dengan hosting, database, login server, dan penyimpanan foto permanen.
